Cara install Open WebUI pakai Docker Compose

1. Apa itu Open WebUI?

Open WebUI adalah antarmuka chat AI yang bisa Anda host sendiri — tampilan dan rasanya mirip ChatGPT, tetapi Anda bebas memilih model. Ia bisa terhubung ke Ollama (model lokal seperti Llama, Qwen, Gemma) atau API apa pun yang kompatibel dengan OpenAI (OpenAI, OpenRouter, Groq, dan lainnya).

Cocok untuk: tim kecil yang ingin satu portal chat AI terpusat, freelancer yang memakai beberapa penyedia model, dan siapa saja yang ingin riwayat chat tersimpan di server sendiri.

  • Repo resmi: https://github.com/open-webui/open-webui
  • Dokumentasi resmi: https://docs.openwebui.com/getting-started/quick-start/

💡 Jujur dulu: Open WebUI tidak punya model sendiri. Ia hanya "meja depan". Anda butuh kunci API dari penyedia model, atau Ollama yang berjalan di mesin yang cukup kuat. Di VPS kecil, cara paling praktis adalah Open WebUI + API model.

2. Prasyarat

  • VPS dengan Ubuntu 24.04 atau 22.04 (64-bit) dan akses sudo.
  • Dasar SSH: bisa login dengan ssh user@IP_SERVER.
  • Salah satu sumber model:
  • Kunci API penyedia yang kompatibel OpenAI (contoh https://api.openai.com/v1), atau
  • Ollama (di server yang sama atau server lain) — butuh RAM jauh lebih besar.
  • Port 3000 terbuka di firewall penyedia VPS (atau pakai tunnel SSH — lihat Akses pribadi pakai tunnel SSH).
  • (Opsional) Domain + reverse proxy untuk HTTPS jika ingin dibagikan ke orang lain.

4. Install Docker

Login ke VPS, lalu perbarui sistem:

sudo apt update && sudo apt upgrade -y

Install Docker Engine + plugin Docker Compose memakai skrip resmi Docker:

curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

Ingin cara manual (repo apt)? Ikuti panduan resmi: https://docs.docker.com/engine/install/ubuntu/

Cek instalasi:

docker --version
docker compose version
sudo docker run hello-world

Jika muncul pesan Hello from Docker!, Docker sudah siap.

(Opsional) Pakai Docker tanpa sudo:

sudo usermod -aG docker ${USER}
exec sg docker newgrp
groups   # pastikan "docker" ada di daftar

5. Install Open WebUI

5.1 Buat folder proyek

mkdir open-webui
cd open-webui

5.2 Buat kunci rahasia (WEBUI_SECRET_KEY)

openssl rand -hex 32

Salin output-nya (64 karakter heksadesimal). Kunci ini menandatangani sesi login.

⚠️ Tetapkan sekali dan simpan. Tanpa kunci tetap, setiap kali container dibuat ulang (misalnya setelah update), semua pengguna akan ter-logout. Simpan salinannya di password manager Anda.

Simpan di file .env supaya tidak ditulis langsung di compose.yaml:

nano .env

WEBUI_SECRET_KEY=tempel-output-openssl-di-sini

Simpan (Ctrl+O, Enter, Ctrl+X), lalu kunci izin file:

chmod 600 .env

5.3 Buat file compose.yaml

nano compose.yaml

Tempel isi berikut (berdasarkan contoh resmi Open WebUI):

services:
  open-webui:
    image: ghcr.io/open-webui/open-webui:main
    container_name: open-webui
    ports:
      - "3000:8080"
    volumes:
      - open-webui:/app/backend/data
    extra_hosts:
      - host.docker.internal:host-gateway
    environment:
      - WEBUI_SECRET_KEY=${WEBUI_SECRET_KEY}
    restart: unless-stopped

volumes:
  open-webui:

💡 VPS kecil dan hanya pakai API model? Ganti baris image: menjadi ghcr.io/open-webui/open-webui:slim.

Apa fungsi file ini (singkat):

  • image — image resmi Open WebUI dari GitHub Container Registry. :main adalah build bergulir (rolling) terbaru.
  • ports 3000:8080 — UI ada di port 3000 server Anda. Jika 3000 sudah terpakai, ganti angka kiri saja (contoh 3001:8080).
  • volume open-webui — menyimpan pengguna, riwayat chat, pengaturan, dan file unggahan. Tetap ada setelah update — jangan dihapus.
  • extra_hosts — memungkinkan container menjangkau Ollama (atau layanan lain) yang berjalan langsung di server lewat host.docker.internal.
  • WEBUI_SECRET_KEY — dibaca dari .env.
  • container_name — nama tetap open-webui (memudahkan perintah docker logs dan tool seperti Watchtower).

5.4 Buka port (ufw)

sudo ufw allow OpenSSH
sudo ufw allow 3000/tcp
sudo ufw enable
sudo ufw status

⚠️ Izinkan OpenSSH dulu sebelum ufw enable, kalau tidak Anda bisa terkunci dari server.

📝 Port yang dipublikasikan Docker biasanya melewati aturan ufw. Jangan menganggap ufw saja sudah melindungi port 3000 — cek juga firewall di panel VPS, atau pakai metode tunnel SSH di bawah.

5.5 Jalankan Open WebUI

sudo docker compose up -d

Unduhan pertama butuh waktu (image :main ~1,6 GB). Untuk menghentikan:

sudo docker compose stop

6. Catatan .env dan keamanan

Variabel Fungsi Nilai aman / contoh
WEBUI_SECRET_KEY Menandatangani sesi login Output openssl rand -hex 32 — tetap, jangan diganti
OLLAMA_BASE_URL (opsional) Alamat Ollama jika tidak di server yang sama http://IP_OLLAMA:11434

Aturan keamanan:

  • Jangan commit .env ke GitHub. Tambahkan .env ke .gitignore.
  • chmod 600 .env supaya hanya pemilik yang bisa membaca.
  • Kunci API penyedia model yang Anda masukkan ke Open WebUI tersimpan di volume open-webui. Backup volume itu dan lindungi.
  • Kalau kunci API bocor, ganti (rotate) di penyedia asal secepatnya.
  • http://IP:3000 adalah HTTP biasa (tidak terenkripsi). Untuk dipakai tim, taruh di belakang reverse proxy dengan HTTPS (misalnya Caddy/Traefik/Nginx) dan baca panduan hardening resmi.

7. Buka UI dan buat akun admin

sudo docker compose ps
sudo docker compose logs -f open-webui

Tunggu sampai log menampilkan Application startup complete (pertama kali bisa sekitar semenit). Tekan Ctrl+C untuk keluar dari log.

Buka browser: http://IP_SERVER:3000

✅ Tampilan yang diharapkan: halaman Get started with Open WebUI dengan tombol Create Admin Account.

  • Akun pertama = admin. Akun ini mengelola pengguna dan semua pengaturan instance. Pakai password kuat dan simpan — kehilangan password admin berarti terkunci dari pengaturan.
  • Setelah akun admin dibuat, pendaftaran baru otomatis ditutup. Untuk mengizinkan orang lain mendaftar: avatar › Settings › Admin › Authentication › aktifkan New Sign Ups. Akun baru akan berstatus Pending sampai Anda setujui di Admin Panel.

Akses pribadi pakai tunnel SSH

Tidak ingin membuka port 3000 ke internet? Ganti baris port di compose.yaml menjadi:

    ports:
      - "127.0.0.1:3000:8080"

Lalu sudo docker compose up -d, dan dari komputer Anda:

ssh -L 3000:localhost:3000 user@IP_SERVER

Buka http://localhost:3000 di komputer Anda. Hanya Anda (lewat SSH) yang bisa mengakses UI.

8. Hubungkan model

Open WebUI tidak punya model sendiri. Buka avatar › Settings › Admin › Connections.

8.1 API kompatibel OpenAI (disarankan untuk VPS kecil)

  1. Klik + di samping Manage OpenAI API Connections.
  2. Masukkan URL penyedia (OpenAI: https://api.openai.com/v1) dan kunci API Anda.
  3. Klik Save. Daftar model akan dimuat otomatis.

Lalu klik New Chat, pilih model di pemilih model, ketik pesan, tekan Enter.

📝 Beberapa penyedia tidak menyediakan daftar model — masukkan ID model secara manual di kolom Model IDs pada koneksi tersebut.

8.2 Ollama di server yang sama

Jika Ollama di-install langsung di server (bukan di Docker), Open WebUI otomatis mencarinya di http://host.docker.internal:11434 — itulah fungsi baris extra_hosts.

Install Ollama (skrip resmi):

curl -fsSL https://ollama.com/install.sh | sh

Ollama harus listen di 0.0.0.0 (bukan hanya 127.0.0.1) agar container Docker bisa menjangkaunya. Untuk layanan systemd:

sudo systemctl edit ollama

Tambahkan:

[Service]
Environment="OLLAMA_HOST=0.0.0.0"

sudo systemctl daemon-reload
sudo systemctl restart ollama

⚠️ Jangan buka port 11434 di firewall publik — Ollama tidak punya login.

Unduh model: sebagai admin, ketik nama model (contoh qwen2.5:3b) di pemilih model pada chat baru lalu konfirmasi pull. Ingat: model lokal butuh RAM besar (lihat kotak ukuran VPS).

8.3 Ollama di server lain

Tambahkan di environment::

      - OLLAMA_BASE_URL=http://IP_OLLAMA:11434

Atau atur URL langsung di Admin › Connections.

9. Error umum

Gejala Penyebab umum Solusi
Browser tidak bisa membuka http://IP:3000 Port diblokir di firewall panel VPS, atau container belum siap Cek sudo docker compose ps, tunggu Application startup complete di log, cek firewall panel VPS
bind: address already in use (port 3000) Aplikasi lain memakai port 3000 Ganti angka kiri, contoh "3001:8080", lalu docker compose up -d
Semua pengguna ter-logout setelah update WEBUI_SECRET_KEY tidak ada / berubah Tetapkan kunci tetap di .env, jangan dibuat ulang
Daftar model kosong (Ollama) Ollama hanya listen di 127.0.0.1 Set OLLAMA_HOST=0.0.0.0 (Bagian 8.2), restart Ollama
Daftar model kosong (API) URL/kunci salah, atau penyedia tidak punya daftar model Pastikan URL diakhiri /v1, cek kunci, isi Model IDs secara manual
Container restart terus / Killed / lambat RAM tidak cukup (OOM) Ganti ke image :slim, tambah swap (di bawah), atau upgrade RAM
Jawaban kosong / chat macet di belakang reverse proxy WebSocket tidak diteruskan Aktifkan dukungan WebSocket (header Upgrade/Connection) di proxy
permission denied ... /var/run/docker.sock User bukan anggota grup docker Pakai sudo, atau jalankan langkah usermod di Bagian 4 lalu login ulang
docker-compose: command not found Memakai perintah lama (v1) Pakai docker compose (dengan spasi, plugin v2)

Cek siapa yang memakai port 3000:

sudo ss -tulpn | grep ':3000 '

Tambah swap 2 GB (untuk VPS 1 GB):

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
free -h

10. Selanjutnya (opsional)

Update Open WebUI (backup dulu — lihat di bawah):

cd ~/open-webui
sudo docker compose pull
sudo docker compose up -d

Data Anda tetap di volume, dan WEBUI_SECRET_KEY yang sama membuat pengguna tetap login.

💡 Ingin lebih terkontrol? :main adalah build bergulir. Untuk production, tetapkan versi, contoh image: ghcr.io/open-webui/open-webui:vX.Y.Z (lihat halaman releases di GitHub), dan naikkan versi secara manual setelah membaca catatan rilis.

Backup volume data:

sudo docker volume ls     # cari nama volume, biasanya open-webui_open-webui
sudo docker compose stop
sudo docker run --rm \
  -v open-webui_open-webui:/data \
  -v "$(pwd)":/backup \
  alpine tar czf /backup/open-webui-$(date +%F).tar.gz -C /data .
sudo docker compose start

Simpan file backup di luar VPS (misalnya komputer Anda atau cloud storage). Simpan juga salinan .env (kunci rahasia) di tempat aman.

Restore ke volume kosong:

sudo docker compose down
sudo docker run --rm \
  -v open-webui_open-webui:/data \
  -v "$(pwd)":/backup \
  alpine sh -c "cd /data && tar xzf /backup/open-webui-TANGGAL.tar.gz"
sudo docker compose up -d

Keamanan dasar: perbarui Ubuntu secara berkala (sudo apt upgrade), pakai kunci SSH (bukan password), pakai HTTPS jika dibagikan ke orang lain, dan jangan ekspos port Ollama 11434 ke internet.

Pertanyaan umum (FAQ)

Apakah Open WebUI sudah termasuk model AI?

Tidak. Open WebUI hanya antarmuka chat. Anda perlu menghubungkan API yang kompatibel dengan OpenAI atau Ollama — lihat Bagian 8 (Hubungkan model).

Sebaiknya pakai image :main atau :slim?

:slim (~200 MB) cocok untuk VPS kecil yang hanya memakai API model. :main (~1.6 GB) untuk fitur lengkap dalam satu container seperti RAG/dokumen, Whisper, dan ekstraksi PDF/Office.

Kenapa semua pengguna ter-logout setelah update?

Biasanya WEBUI_SECRET_KEY tidak diatur secara tetap. Buat sekali dengan openssl rand -hex 32, simpan di .env, dan jangan diubah (Bagian 5.2).

Bisakah memakai Open WebUI tanpa membuka port 3000 ke internet?

Bisa. Ikat port ke 127.0.0.1 dan akses lewat tunnel SSH — lihat Akses pribadi pakai tunnel SSH.
