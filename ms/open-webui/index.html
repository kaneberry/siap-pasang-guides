Cara pasang Open WebUI guna Docker Compose

1. Apa itu Open WebUI?

Open WebUI ialah antara muka chat AI yang anda hos sendiri — rupa dan rasa macam ChatGPT, tetapi anda pilih model sendiri. Ia boleh sambung ke Ollama (model tempatan seperti Llama, Qwen, Gemma) atau mana-mana API yang serasi OpenAI (OpenAI, OpenRouter, Groq, dan lain-lain).

Sesuai untuk: pasukan kecil yang mahu satu portal chat AI berpusat, freelancer yang guna beberapa penyedia model, dan sesiapa yang mahu sejarah chat disimpan di server sendiri.

  • Repo rasmi: https://github.com/open-webui/open-webui
  • Dokumentasi rasmi: https://docs.openwebui.com/getting-started/quick-start/

💡 Jujur dulu: Open WebUI tiada model sendiri. Ia hanya "kaunter depan". Anda perlukan sama ada kunci API daripada penyedia model, atau Ollama yang berjalan pada mesin cukup kuat. Pada VPS kecil, cara paling praktikal ialah Open WebUI + API model.

2. Prasyarat

  • VPS dengan Ubuntu 24.04 atau 22.04 (64-bit) dan akses sudo.
  • Asas SSH: boleh log masuk ssh user@IP_SERVER.
  • Salah satu sumber model:
  • Kunci API penyedia serasi OpenAI (contoh https://api.openai.com/v1), atau
  • Ollama (pada server yang sama atau server lain) — perlukan RAM jauh lebih besar.
  • Port 3000 dibuka di firewall penyedia VPS (atau guna terowong SSH — lihat Akses peribadi guna terowong SSH).
  • (Pilihan) Domain + reverse proxy untuk HTTPS jika mahu kongsi dengan orang lain.

4. Pasang Docker

Log masuk ke VPS, kemudian kemas kini sistem:

sudo apt update && sudo apt upgrade -y

Pasang Docker Engine + plugin Docker Compose guna skrip rasmi Docker:

curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

Mahu cara manual (repo apt)? Ikut panduan rasmi: https://docs.docker.com/engine/install/ubuntu/

Semak pemasangan:

docker --version
docker compose version
sudo docker run hello-world

Jika anda nampak mesej Hello from Docker!, Docker sudah sedia.

(Pilihan) Guna Docker tanpa sudo:

sudo usermod -aG docker ${USER}
exec sg docker newgrp
groups   # pastikan "docker" ada dalam senarai

5. Pasang Open WebUI

5.1 Cipta folder projek

mkdir open-webui
cd open-webui

5.2 Jana kunci rahsia (WEBUI_SECRET_KEY)

openssl rand -hex 32

Salin output (64 aksara heks). Kunci ini menandatangani sesi log masuk.

⚠️ Tetapkan sekali dan simpan. Tanpa kunci tetap, setiap kali bekas dicipta semula (contoh selepas kemas kini), semua pengguna akan terlog keluar. Simpan salinan di pengurus kata laluan anda.

Simpan dalam fail .env supaya tidak tertulis terus dalam compose.yaml:

nano .env

WEBUI_SECRET_KEY=tampal-output-openssl-di-sini

Simpan (Ctrl+O, Enter, Ctrl+X), kemudian kunci kebenaran fail:

chmod 600 .env

5.3 Cipta fail compose.yaml

nano compose.yaml

Tampal kandungan ini (berdasarkan contoh rasmi Open WebUI):

services:
  open-webui:
    image: ghcr.io/open-webui/open-webui:main
    container_name: open-webui
    ports:
      - "3000:8080"
    volumes:
      - open-webui:/app/backend/data
    extra_hosts:
      - host.docker.internal:host-gateway
    environment:
      - WEBUI_SECRET_KEY=${WEBUI_SECRET_KEY}
    restart: unless-stopped

volumes:
  open-webui:

💡 VPS kecil dan guna API model sahaja? Tukar baris image: kepada ghcr.io/open-webui/open-webui:slim.

Apa yang fail ini buat (ringkas):

  • image — imej rasmi Open WebUI dari GitHub Container Registry. :main ialah binaan bergulir (rolling) terkini.
  • ports 3000:8080 — UI di port 3000 server anda. Jika 3000 sudah dipakai, tukar nombor kiri sahaja (contoh 3001:8080).
  • volume open-webui — simpan pengguna, sejarah chat, tetapan dan fail muat naik. Kekal selepas kemas kini — jangan padam.
  • extra_hosts — membolehkan bekas mencapai Ollama (atau servis lain) yang berjalan terus pada server melalui host.docker.internal.
  • WEBUI_SECRET_KEY — dibaca dari .env.
  • container_name — nama tetap open-webui (memudahkan arahan docker logs dan alat seperti Watchtower).

5.4 Buka port (ufw)

sudo ufw allow OpenSSH
sudo ufw allow 3000/tcp
sudo ufw enable
sudo ufw status

⚠️ Benarkan OpenSSH dulu sebelum ufw enable, kalau tidak anda boleh terkunci dari server.

📝 Port yang diterbitkan oleh Docker biasanya memintas peraturan ufw. Jangan anggap ufw sahaja melindungi port 3000 — semak juga firewall di panel VPS, atau guna kaedah terowong SSH di bawah.

5.5 Hidupkan Open WebUI

sudo docker compose up -d

Muat turun kali pertama ambil masa (imej :main ~1.6 GB). Untuk hentikan:

sudo docker compose stop

6. Nota .env dan keselamatan

Pemboleh ubah Fungsi Nilai selamat / contoh
WEBUI_SECRET_KEY Tandatangan sesi log masuk Output openssl rand -hex 32 — tetap, jangan tukar
OLLAMA_BASE_URL (pilihan) Alamat Ollama jika bukan di server sama http://IP_OLLAMA:11434

Peraturan keselamatan:

  • Jangan commit .env ke GitHub. Tambah .env dalam .gitignore.
  • chmod 600 .env supaya hanya pemilik boleh baca.
  • Kunci API penyedia model yang anda masukkan dalam Open WebUI disimpan dalam volume open-webui. Backup volume itu dan lindunginya.
  • Kalau kunci API bocor, tukar (rotate) di penyedia asal dengan segera.
  • http://IP:3000 ialah HTTP biasa (tidak disulitkan). Untuk kegunaan pasukan, letak di belakang reverse proxy dengan HTTPS (contoh Caddy/Traefik/Nginx) dan baca panduan hardening rasmi.

7. Buka UI dan cipta akaun admin

sudo docker compose ps
sudo docker compose logs -f open-webui

Tunggu sehingga log menunjukkan Application startup complete (kali pertama mungkin ambil seminit). Tekan Ctrl+C untuk keluar dari log.

Buka pelayar: http://IP_SERVER:3000

✅ Skrin dijangka: halaman Get started with Open WebUI dengan butang Create Admin Account.

  • Akaun pertama = admin. Ia mengurus pengguna dan semua tetapan instance. Guna kata laluan kuat dan simpan — hilang kata laluan admin bermakna terkunci dari tetapan.
  • Selepas akaun admin wujud, pendaftaran baharu ditutup secara automatik. Untuk benarkan orang lain mendaftar: avatar › Settings › Admin › Authentication › hidupkan New Sign Ups. Akaun baharu akan berstatus Pending sehingga anda luluskan di Admin Panel.

Akses peribadi guna terowong SSH

Tidak mahu buka port 3000 ke internet? Tukar baris port dalam compose.yaml kepada:

    ports:
      - "127.0.0.1:3000:8080"

Kemudian sudo docker compose up -d, dan dari komputer anda:

ssh -L 3000:localhost:3000 user@IP_SERVER

Buka http://localhost:3000 di komputer anda. Hanya anda (melalui SSH) boleh capai UI.

8. Sambung model

Open WebUI tiada model sendiri. Pergi ke avatar › Settings › Admin › Connections.

8.1 API serasi OpenAI (disyorkan untuk VPS kecil)

  1. Klik + di sebelah Manage OpenAI API Connections.
  2. Masukkan URL penyedia (OpenAI: https://api.openai.com/v1) dan kunci API anda.
  3. Klik Save. Senarai model akan dimuatkan secara automatik.

Kemudian klik New Chat, pilih model dalam pemilih model, taip mesej, tekan Enter.

📝 Sesetengah penyedia tidak menerbitkan senarai model — masukkan ID model secara manual di ruangan Model IDs pada sambungan itu.

8.2 Ollama pada server yang sama

Jika Ollama dipasang terus pada server (bukan dalam Docker), Open WebUI akan mencarinya secara automatik di http://host.docker.internal:11434 — itulah fungsi baris extra_hosts.

Pasang Ollama (skrip rasmi):

curl -fsSL https://ollama.com/install.sh | sh

Ollama mesti mendengar pada 0.0.0.0 (bukan hanya 127.0.0.1) supaya bekas Docker boleh capai. Untuk servis systemd:

sudo systemctl edit ollama

Tambah:

[Service]
Environment="OLLAMA_HOST=0.0.0.0"

sudo systemctl daemon-reload
sudo systemctl restart ollama

⚠️ Jangan buka port 11434 di firewall awam — Ollama tiada log masuk.

Muat turun model: sebagai admin, taip nama model (contoh qwen2.5:3b) dalam pemilih model pada chat baharu dan sahkan pull. Ingat: model tempatan perlukan RAM besar (lihat kotak saiz VPS).

8.3 Ollama pada server lain

Tambah dalam environment::

      - OLLAMA_BASE_URL=http://IP_OLLAMA:11434

Atau tetapkan URL terus di Admin › Connections.

Semak siapa guna port 3000:

sudo ss -tulpn | grep ':3000 '

Tambah swap 2 GB (untuk VPS 1 GB):

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
free -h

10. Seterusnya (pilihan)

Kemas kini Open WebUI (backup dulu — lihat di bawah):

cd ~/open-webui
sudo docker compose pull
sudo docker compose up -d

Data anda kekal dalam volume, dan WEBUI_SECRET_KEY yang sama memastikan pengguna kekal log masuk.

💡 Mahu lebih terkawal? :main ialah binaan bergulir. Untuk production, tetapkan versi, contoh image: ghcr.io/open-webui/open-webui:vX.Y.Z (rujuk halaman releases di GitHub), dan naikkan versi secara manual selepas baca nota keluaran.

Backup volume data:

sudo docker volume ls     # cari nama volume, biasanya open-webui_open-webui
sudo docker compose stop
sudo docker run --rm \
  -v open-webui_open-webui:/data \
  -v "$(pwd)":/backup \
  alpine tar czf /backup/open-webui-$(date +%F).tar.gz -C /data .
sudo docker compose start

Simpan fail backup di luar VPS (contoh komputer anda atau storan awan). Simpan juga salinan .env (kunci rahsia) di tempat selamat.

Pulihkan (restore) ke volume kosong:

sudo docker compose down
sudo docker run --rm \
  -v open-webui_open-webui:/data \
  -v "$(pwd)":/backup \
  alpine sh -c "cd /data && tar xzf /backup/open-webui-TARIKH.tar.gz"
sudo docker compose up -d

Keselamatan asas: kemas kini Ubuntu secara berkala (sudo apt upgrade), guna kunci SSH (bukan kata laluan), guna HTTPS jika dikongsi dengan orang lain, dan jangan dedahkan port Ollama 11434 ke internet.

Soalan lazim (FAQ)

Adakah Open WebUI datang dengan model AI sendiri?

Tidak. Open WebUI hanya antara muka chat. Anda perlu sambung API yang serasi OpenAI atau Ollama — lihat Seksyen 8 (Sambung model).

Patut guna imej :main atau :slim?

:slim (~200 MB) sesuai untuk VPS kecil yang guna API model sahaja. :main (~1.6 GB) untuk ciri lengkap dalam satu bekas seperti RAG/dokumen, Whisper dan ekstrak PDF/Office.

Kenapa semua pengguna terlog keluar selepas kemas kini?

Biasanya WEBUI_SECRET_KEY tidak ditetapkan secara kekal. Jana sekali dengan openssl rand -hex 32, simpan dalam .env, dan jangan tukar (Seksyen 5.2).

Boleh guna Open WebUI tanpa buka port 3000 ke internet?

Boleh. Ikat port kepada 127.0.0.1 dan capai melalui terowong SSH — lihat Akses peribadi guna terowong SSH.
