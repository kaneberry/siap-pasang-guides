Cara pasang Immich guna Docker Compose

1. Apa itu Immich?

Immich ialah aplikasi foto dan video self-hosted — alternatif kepada Google Photos atau iCloud Photos yang berjalan di server anda sendiri. Aplikasi mudah alih (Android/iOS) boleh backup foto secara automatik ke server, dan antara muka web membolehkan anda lihat garis masa, album, peta, kongsi album serta cari foto mengikut wajah atau kandungan (machine learning berjalan di server anda).

Sesuai untuk: keluarga atau individu yang mahu simpan foto sendiri tanpa bergantung pada storan awan berbayar, dan sesiapa yang mahu kawalan penuh ke atas data peribadi.

  • Repo rasmi: https://github.com/immich-app/immich
  • Dokumentasi rasmi: https://docs.immich.app/install/docker-compose

💡 Jujur dulu: Immich lebih berat daripada kebanyakan alat self-hosted — minimum rasmi ialah 6 GB RAM. Faktor paling besar pula ialah storan: pustaka foto anda akan membesar setiap tahun, dan thumbnail serta video yang ditranskod menambah lebih kurang 10–20% lagi. Immich bukan pengganti backup — anda tetap perlukan salinan di tempat lain (lihat Seksyen 8).

2. Prasyarat

  • VPS dengan Ubuntu 24.04 atau 22.04 (64-bit) dan akses sudo. Docs rasmi mengesyorkan Linux; Windows/macOS tidak digalakkan untuk server.
  • Minimum rasmi: RAM 6 GB, CPU 2 teras (disyorkan 8 GB dan 4 teras).
  • CPU amd64 atau arm64. Untuk amd64, bekas machine learning Immich v3 perlukan tahap x86-64-v2 (kebanyakan CPU sejak ~2012).
  • Docker Engine dengan plugin Docker Compose — arahannya docker compose, bukan docker-compose (dipasang dalam Seksyen 4).
  • Storan yang cukup untuk semua foto/video anda, dengan sistem fail Unix (contoh EXT4). Pangkalan data mesti di cakera tempatan (SSD lebih baik).
  • Alat wget dan asas SSH: boleh log masuk ssh user@IP_SERVER.
  • Port 2283 dibuka di firewall penyedia VPS — atau guna terowong SSH (lihat Akses peribadi guna terowong SSH), yang lebih selamat.

3. 📦 Saiz VPS disyorkan

📦 Saiz VPS disyorkan untuk Immich

RAM vCPU Disk
Lebih selesa (disyorkan rasmi) 8 GB 4 100 GB+ (ikut saiz pustaka)
Minimum (rasmi) 6 GB 2 40 GB+

RAM dan vCPU diambil daripada keperluan rasmi Immich (minimum 6 GB / 2 teras, disyorkan 8 GB / 4 teras). Saiz disk ialah cadangan kami: kira saiz semua foto dan video anda, tambah 10–20% untuk thumbnail dan transkod, serta beberapa GB untuk pangkalan data (biasanya 1–3 GB) dan sistem. Untuk pustaka besar, pertimbangkan block storage tambahan untuk UPLOAD_LOCATION — tetapi kekalkan pangkalan data pada cakera tempatan.

Pilihan penyedia (pautan rasmi): Vultr · DigitalOcean · Hostinger VPS

Harga berubah — semak harga semasa di laman rasmi. Atau guna mana-mana VPS / PC sendiri.

ℹ️ Pendedahan: Pautan dalam kotak ini akan menjadi pautan afiliasi apabila pautan afiliasi diaktifkan; kami mungkin dapat komisen tanpa kos tambahan kepada anda. Buat masa ini semua pautan ialah pautan rasmi biasa. Baca pendedahan penuh.

4. Pasang Docker

Log masuk ke VPS, kemudian kemas kini sistem:

sudo apt update && sudo apt upgrade -y

Pasang Docker Engine + plugin Docker Compose guna skrip rasmi Docker:

curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

Mahu cara manual (repo apt)? Ikut panduan rasmi: https://docs.docker.com/engine/install/ubuntu/

⚠️ Jangan guna pakej docker.io atau docker-compose daripada repo Ubuntu. Docs rasmi Immich menyatakan pakej ini menyebabkan ralat seperti unknown shorthand flag: 'd' in -d. Guna Docker Engine rasmi seperti di atas.

Semak pemasangan:

docker --version
docker compose version
sudo docker run hello-world

Jika anda nampak mesej Hello from Docker! dan docker compose version memaparkan nombor versi, Docker sudah sedia.

(Pilihan) Guna Docker tanpa sudo:

sudo usermod -aG docker ${USER}
exec sg docker newgrp
groups   # pastikan "docker" ada dalam senarai

5. Pasang Immich

5.1 Cipta folder projek

mkdir ./immich-app
cd ./immich-app

Semua fail Immich (docker-compose.yml, .env, dan secara lalai folder foto serta pangkalan data) akan berada dalam folder ini.

5.2 Muat turun docker-compose.yml dan .env

Arahan rasmi ini muat turun fail daripada keluaran terkini Immich di GitHub:

wget -O docker-compose.yml https://github.com/immich-app/immich/releases/latest/download/docker-compose.yml
wget -O .env https://github.com/immich-app/immich/releases/latest/download/example.env

Ketika panduan ini ditulis (2 Nov 2026), keluaran terkini ialah v3.3.5 (diterbitkan 21 Okt 2026).

📝 Muat turun melalui pelayar? Pastikan anda namakan semula example.env kepada .env.

5.3 Isi fail .env

Jana kata laluan pangkalan data yang rawak (huruf dan nombor sahaja):

openssl rand -hex 24

Salin output, kemudian buka .env:

nano .env

Ubah baris-baris ini:

# Lokasi foto/video yang dimuat naik — mesti ada ruang cakera yang cukup
UPLOAD_LOCATION=./library

# Lokasi fail pangkalan data — cakera tempatan sahaja (BUKAN network share)
DB_DATA_LOCATION=./postgres

# Buang tanda # dan tetapkan zon waktu anda
TZ=Asia/Kuala_Lumpur

# Versi Immich (v3 = sentiasa ikut keluaran v3 terkini)
IMMICH_VERSION=v3

# Tukar daripada "postgres" kepada output openssl tadi (A-Za-z0-9 sahaja)
DB_PASSWORD=tampal-output-openssl-di-sini

Simpan (Ctrl+O, Enter, Ctrl+X), kemudian kunci kebenaran fail:

chmod 600 .env

📌 IMMICH_VERSION: nilai lalai v3 mengikut keluaran v3 terkini setiap kali anda tarik imej. Mahu kawalan penuh? Kunci pada versi tertentu, contoh IMMICH_VERSION=v3.3.5 — tetapi anda perlu kemas kini nilai ini sendiri setiap kali naik taraf.

5.4 Hidupkan Immich

sudo docker compose up -d

Muat turun kali pertama ambil masa beberapa minit. Empat bekas akan dimulakan:

  • immich_server — aplikasi web dan API (port 2283)
  • immich_machine_learning — carian pintar dan pengecaman wajah
  • immich_postgres — pangkalan data
  • immich_redis — baris gilir kerja (imej Valkey)

Apa yang perlu tahu (ringkas):

  • Foto anda berada dalam folder UPLOAD_LOCATION (lalai ./library), pangkalan data dalam DB_DATA_LOCATION (lalai ./postgres). Jangan padam kedua-dua folder ini.
  • Untuk hentikan semua bekas: sudo docker compose down (data kekal).

6. Nota .env dan keselamatan

Pemboleh ubah Fungsi Nilai selamat / contoh
UPLOAD_LOCATION Folder foto/video, thumbnail dan backup pangkalan data automatik ./library atau cakera besar, contoh /mnt/foto
DB_DATA_LOCATION Folder fail Postgres ./postgres — cakera tempatan (SSD), bukan NFS/SMB
DB_PASSWORD Kata laluan Postgres Output openssl rand -hex 24 (A-Za-z0-9 sahaja)
TZ Zon waktu server Asia/Kuala_Lumpur
IMMICH_VERSION Tag imej Immich v3 atau versi tetap, contoh v3.3.5

Peraturan keselamatan:

  • Jangan commit .env ke GitHub. chmod 600 .env supaya hanya pemilik boleh baca.
  • Postgres tidak didedahkan ke internet dalam docker-compose.yml rasmi — jangan tambah port pangkalan data atau Redis.
  • http://IP_SERVER:2283 ialah HTTP biasa (tidak disulitkan). Membuka port 2283 ke internet tanpa HTTPS berisiko — kata laluan dan foto peribadi dihantar tanpa penyulitan. Guna terowong SSH untuk mula, dan sediakan HTTPS sebelum guna aplikasi mudah alih dari luar rumah (lihat Seksyen 10).
  • Port yang diterbitkan oleh Docker biasanya memintas peraturan ufw. Jangan anggap ufw sahaja melindungi port 2283 — semak juga firewall di panel VPS.

7. Sahkan dan cipta akaun admin

sudo docker compose ps

✅ Keempat-empat bekas patut berstatus Up — immich_server akan bertukar kepada healthy selepas beberapa ketika.

Lihat log jika ada bekas yang restart berulang:

sudo docker compose logs -f immich-server
sudo docker compose logs -f immich-machine-learning

Buka pelayar ke:

http://IP_SERVER:2283

✅ Skrin dijangka: halaman alu-aluan Immich. Klik Getting Started dan ikut arahan untuk daftar. Pengguna pertama yang mendaftar menjadi admin.

⚠️ Daftar akaun admin segera selepas Immich hidup. Selagi belum ada admin, sesiapa yang boleh capai server anda boleh mendaftar dahulu dan menjadi admin. Terowong SSH (di bawah) mengelakkan risiko ini.

Akses peribadi guna terowong SSH

Tidak mahu buka port 2283 ke internet? Dalam docker-compose.yml, di bawah servis immich-server, tukar baris port:

    ports:
      - '127.0.0.1:2283:2283'

Kemudian mulakan semula:

sudo docker compose down
sudo docker compose up -d

Dari komputer anda (terminal baharu):

ssh -L 2283:localhost:2283 user@IP_SERVER

Buka http://localhost:2283 di komputer anda. Hanya anda (melalui SSH) boleh capai Immich.

📝 Cara ikat ke 127.0.0.1 ini ialah tip kami (format port standard Docker Compose), bukan langkah dalam docs rasmi Immich. Aplikasi mudah alih tidak boleh guna terowong ini dari luar — untuk itu, sediakan HTTPS (Seksyen 10). Ingat untuk ulang perubahan ini jika anda muat turun docker-compose.yml baharu.

8. Selepas pasang

Ringkasan langkah daripada Immich Docs — Post Installation:

  1. Pengguna lain (pilihan): Administration › Users › Create user untuk ahli keluarga.
  2. Storage template (pilihan): Administration › Settings › Storage Template menentukan susunan folder fail di cakera (lalai: Tahun/Tahun-Bulan-Hari/NamaFail). Tetapkan awal sebelum muat naik banyak foto.
  3. Aplikasi mudah alih: muat turun Immich di Google Play, App Store, F-Droid atau GitHub Releases. Log masuk dengan URL server, contoh http://IP_SERVER:2283 (atau URL HTTPS anda).
  4. Backup foto dari telefon: dalam aplikasi, tekan ikon awan, pilih album, kemudian Enable Backup.

Backup server (wajib)

Docs rasmi menekankan strategi 3-2-1: sekurang-kurangnya tiga salinan, pada dua jenis media, dengan satu salinan di luar lokasi.

  • Immich membuat backup pangkalan data secara automatik ke UPLOAD_LOCATION/backups (lalai: setiap hari jam 2:00 pagi, simpan 14 salinan terakhir). Tetapan di Administration › Settings › Database Dump Settings.
  • Backup pangkalan data tidak mengandungi foto/video — hanya metadata. Anda perlu backup keseluruhan folder UPLOAD_LOCATION ke tempat lain (cakera lain, server lain atau storan awan) guna alat backup anda sendiri.
  • Ikut panduan rasmi untuk butiran dan cara restore: Immich Docs — Backup and Restore.

9. Ralat biasa

Simptom Punca biasa Penyelesaian
unknown shorthand flag: 'd' in -d atau open: permission denied Pakej Docker distro (docker.io) Pasang Docker Engine rasmi (Seksyen 4), termasuk buang pakej lama
'name' does not match any of the regexes: '^x-' Guna docker-compose (versi lama) Guna docker compose (dengan ruang) daripada Docker Engine rasmi
can't set healthcheck.start_interval as feature require Docker Engine v25 or later Docker Engine lebih lama daripada v25 Kemas kini Docker; atau, seperti docs rasmi, komen keluar baris start_interval dalam bahagian database di docker-compose.yml
bind: address already in use (port 2283) Servis lain guna port 2283 Tukar port hos, contoh '2284:2283', kemudian buka http://IP_SERVER:2284
Bekas restart berulang / Killed / muat naik sangat perlahan RAM tak cukup (OOM) Pastikan sekurang-kurangnya 6 GB RAM; 8 GB disyorkan
immich_machine_learning gagal bermula pada server amd64 lama CPU tiada sokongan x86-64-v2 Pilih VPS/jenis CPU yang lebih baharu (lihat Requirements)
Ralat Postgres / pangkalan data rosak DB_DATA_LOCATION pada network share atau sistem fail NTFS/FAT Letak DB_DATA_LOCATION pada cakera tempatan dengan sistem fail Unix (EXT4 dsb.)
Tidak boleh buka http://IP_SERVER:2283 Port belum dibuka di firewall VPS, atau port diikat ke 127.0.0.1 Buka port 2283 di panel VPS, atau guna terowong SSH
Aplikasi mudah alih tidak dapat sambung URL salah (tiada :2283 / http vs https) Masukkan URL penuh; jika di belakang reverse proxy, pastikan /.well-known/immich dihalakan ke Immich
permission denied ... /var/run/docker.sock Pengguna bukan ahli kumpulan docker Guna sudo, atau jalankan langkah usermod dalam Seksyen 4 dan log masuk semula

Semak siapa guna port 2283:

sudo ss -tulpn | grep -E ':2283 '

Lebih banyak jawapan: Immich Docs — FAQ.

10. Seterusnya (pilihan)

HTTPS: jangan biarkan Immich terbuka di HTTP biasa, terutamanya jika aplikasi mudah alih akan backup dari luar rumah. Letak Immich di belakang reverse proxy (contoh Nginx, Caddy atau Traefik) dengan sijil TLS dan domain anda sendiri. Ikut keperluan rasmi: Immich Docs — Reverse Proxy. Perkara penting daripada docs tersebut:

  • Immich mesti dihidangkan pada akar (sub)domain, contoh https://foto.contoh.com — bukan sub-laluan seperti /immich.
  • Proksi mesti hantar header Host, X-Real-IP, X-Forwarded-Proto, X-Forwarded-For dan benarkan muat naik fail besar.

Ubah tetapan: edit .env, kemudian:

sudo docker compose up -d

Kemas kini Immich (ikut Immich Docs — Upgrading):

  1. Baca nota keluaran di https://github.com/immich-app/immich/releases — terutamanya bahagian breaking changes.
  2. Backup dahulu (Seksyen 8).
  3. Untuk naik taraf versi major, kemas kini aplikasi mudah alih dahulu — server hanya serasi dengan aplikasi versi major yang sepadan.
  4. Jika anda kunci versi, tukar IMMICH_VERSION dalam .env (contoh v3.3.5 → versi sasaran).
  5. Tarik imej baharu dan hidupkan semula:
cd ~/immich-app
sudo docker compose pull && sudo docker compose up -d
  1. (Pilihan) Kosongkan imej lama: sudo docker image prune

⚠️ Turun versi (downgrade) tidak disokong oleh Immich, walaupun dalam versi minor yang sama. Sebab itu backup sebelum kemas kini sangat penting. Jika nota keluaran meminta docker-compose.yml baharu, muat turun semula dan ulang perubahan anda — jangan tulis ganti .env anda.

Keselamatan asas: kemas kini Ubuntu secara berkala (sudo apt upgrade), guna kunci SSH (bukan kata laluan), dan semak storan kosong dengan df -h sebelum cakera penuh.
