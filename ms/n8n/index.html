Cara pasang n8n guna Docker Compose

1. Apa itu n8n?

n8n ialah alat automasi aliran kerja (workflow) — macam Zapier/Make, tetapi anda boleh hos sendiri. Anda sambung apl (Google Sheets, Telegram, WhatsApp API, LLM, webhook) dan bina automasi secara visual.

Sesuai untuk: pemilik PKS, freelancer, dan pasukan IT kecil yang mahu automasi tanpa yuran per-tugas.

  • Repo rasmi: https://github.com/n8n-io/n8n
  • Dokumentasi rasmi: https://docs.n8n.io/hosting/installation/server-setups/docker-compose/

💡 Jujur dulu: n8n sendiri menyatakan self-hosting sesuai untuk pengguna yang biasa urus server. Kalau anda tak mahu jaga server, backup dan keselamatan, n8n Cloud ialah pilihan yang lebih mudah: https://n8n.io/pricing/

2. Prasyarat

  • VPS dengan Ubuntu 24.04 atau 22.04 (64-bit) dan akses sudo.
  • Domain atau subdomain (contoh n8n.contoh.com) — diperlukan untuk HTTPS automatik. Tiada domain? Lihat Pilihan tanpa domain.
  • Asas SSH: boleh log masuk ssh user@IP_SERVER.
  • Emel untuk sijil SSL Let's Encrypt.
  • Port 80 dan 443 dibuka di firewall penyedia VPS.

4. Pasang Docker

Log masuk ke VPS, kemudian kemas kini sistem:

sudo apt update && sudo apt upgrade -y

Pasang Docker Engine + plugin Docker Compose guna skrip rasmi Docker:

curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

Mahu cara manual (repo apt)? Ikut panduan rasmi: https://docs.docker.com/engine/install/ubuntu/

Semak pemasangan:

docker --version
docker compose version
sudo docker run hello-world

Jika anda nampak mesej Hello from Docker!, Docker sudah sedia.

(Pilihan) Guna Docker tanpa sudo:

sudo usermod -aG docker ${USER}
exec sg docker newgrp
groups   # pastikan "docker" ada dalam senarai

5. Pasang n8n

5.1 Tetapkan DNS

Di panel domain anda, tambah rekod A:

Jenis Nama Destinasi
A n8n (atau subdomain pilihan) IP_SERVER_ANDA

Tunggu beberapa minit. Semak dengan ping n8n.contoh.com — ia patut tunjuk IP server anda.

5.2 Buka firewall (ufw)

sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
sudo ufw status

⚠️ Benarkan OpenSSH dulu sebelum ufw enable, kalau tidak anda boleh terkunci dari server.

5.3 Cipta folder projek dan fail .env

mkdir n8n-compose
cd n8n-compose
nano .env

Tampal dan tukar nilai ikut maklumat anda:

# Domain utama
DOMAIN_NAME=contoh.com

# Subdomain — n8n akan berada di https://n8n.contoh.com
SUBDOMAIN=n8n

# Zon masa untuk nod Schedule/Cron
GENERIC_TIMEZONE=Asia/Kuala_Lumpur

# Emel untuk sijil TLS/SSL (Let's Encrypt)
SSL_EMAIL=anda@contoh.com

Simpan (Ctrl+O, Enter, Ctrl+X), kemudian kunci kebenaran fail:

chmod 600 .env

5.4 Cipta folder fail tempatan

Folder ini dikongsi antara n8n dan server (contoh untuk nod Read/Write Files from Disk):

mkdir local-files

5.5 Cipta fail compose.yaml

nano compose.yaml

Tampal kandungan ini (sama seperti contoh rasmi n8n):

services:
  traefik:
    image: "traefik"
    restart: always
    command:
      - "--api.insecure=true"
      - "--providers.docker=true"
      - "--providers.docker.exposedbydefault=false"
      - "--entrypoints.web.address=:80"
      - "--entrypoints.web.http.redirections.entryPoint.to=websecure"
      - "--entrypoints.web.http.redirections.entrypoint.scheme=https"
      - "--entrypoints.websecure.address=:443"
      - "--certificatesresolvers.mytlschallenge.acme.tlschallenge=true"
      - "--certificatesresolvers.mytlschallenge.acme.email=${SSL_EMAIL}"
      - "--certificatesresolvers.mytlschallenge.acme.storage=/letsencrypt/acme.json"
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - traefik_data:/letsencrypt
      - /var/run/docker.sock:/var/run/docker.sock:ro

  n8n:
    image: n8nio/n8n
    restart: always
    ports:
      - "127.0.0.1:5678:5678"
    labels:
      - traefik.enable=true
      - traefik.http.routers.n8n.rule=Host(`${SUBDOMAIN}.${DOMAIN_NAME}`)
      - traefik.http.routers.n8n.tls=true
      - traefik.http.routers.n8n.entrypoints=web,websecure
      - traefik.http.routers.n8n.tls.certresolver=mytlschallenge
      - traefik.http.middlewares.n8n.headers.SSLRedirect=true
      - traefik.http.middlewares.n8n.headers.STSSeconds=315360000
      - traefik.http.middlewares.n8n.headers.browserXSSFilter=true
      - traefik.http.middlewares.n8n.headers.contentTypeNosniff=true
      - traefik.http.middlewares.n8n.headers.forceSTSHeader=true
      - traefik.http.middlewares.n8n.headers.SSLHost=${DOMAIN_NAME}
      - traefik.http.middlewares.n8n.headers.STSIncludeSubdomains=true
      - traefik.http.middlewares.n8n.headers.STSPreload=true
      - traefik.http.routers.n8n.middlewares=n8n@docker
    environment:
      - N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true
      - N8N_HOST=${SUBDOMAIN}.${DOMAIN_NAME}
      - N8N_PORT=5678
      - N8N_PROTOCOL=https
      - NODE_ENV=production
      - N8N_WEBHOOK_URL=https://${SUBDOMAIN}.${DOMAIN_NAME}/
      - GENERIC_TIMEZONE=${GENERIC_TIMEZONE}
      - TZ=${GENERIC_TIMEZONE}
      - N8N_RESTRICT_FILE_ACCESS_TO=/files
    volumes:
      - n8n_data:/home/node/.n8n
      - ./local-files:/files

volumes:
  n8n_data:
  traefik_data:

Apa yang fail ini buat (ringkas):

  • traefik — "penjaga pintu". Terima trafik di port 80/443, dapatkan sijil HTTPS percuma secara automatik, dan hantar ke n8n.
  • n8n — aplikasi n8n. Port 5678 hanya dibuka pada 127.0.0.1 (dalam server sahaja), jadi orang luar mesti lalu HTTPS melalui Traefik.
  • n8n_data — simpan pangkalan data SQLite dan kunci penyulitan (encryption key) n8n. Jangan padam!
  • traefik_data — simpan sijil SSL.
  • ./local-files → /files — folder kongsi. Dalam n8n, guna laluan /files.

📝 N8N_WEBHOOK_URL wujud mulai n8n 2.30.0. Jika anda guna versi lebih lama, tukar kepada WEBHOOK_URL.

5.6 Hidupkan n8n

sudo docker compose up -d

Untuk hentikan:

sudo docker compose stop

6. Nota .env

Pemboleh ubah Fungsi Nilai selamat / contoh
DOMAIN_NAME Domain utama anda contoh.com
SUBDOMAIN Subdomain untuk n8n n8n → https://n8n.contoh.com
GENERIC_TIMEZONE Zon masa nod jadual (default New York jika kosong) Asia/Kuala_Lumpur
SSL_EMAIL Emel notis sijil Let's Encrypt emel yang anda baca

Peraturan keselamatan:

  • Jangan commit .env ke GitHub. Tambah .env dalam .gitignore.
  • chmod 600 .env supaya hanya pemilik boleh baca.
  • Kunci API/token yang anda masukkan dalam n8n disimpan sebagai credentials yang disulitkan dengan kunci dalam volume n8n_data. Backup volume itu — tanpa kunci, credentials tak boleh dibuka.
  • Kalau token bocor, tukar (rotate) di penyedia asal dengan segera.
  • Tiada kata laluan lalai: anda cipta akaun pemilik (owner) sendiri pada kali pertama buka n8n — guna kata laluan kuat.

7. Sahkan

sudo docker compose ps

Anda patut nampak dua servis (traefik dan n8n) dengan status running / Up.

Lihat log jika perlu:

sudo docker compose logs -f n8n
sudo docker compose logs -f traefik

Buka pelayar: https://n8n.contoh.com (ikut domain anda).

✅ Skrin dijangka: halaman n8n untuk cipta akaun pemilik (owner account) — isi emel, nama dan kata laluan. Selepas itu anda masuk ke editor aliran kerja.

n8n hanya boleh dicapai melalui HTTPS, bukan HTTP biasa.

Pilihan tanpa domain (terowong SSH)

Tiada domain lagi? Anda boleh cuba n8n secara peribadi tanpa membuka port awam:

# Di VPS:
sudo docker volume create n8n_data
sudo docker run -d --name n8n --restart unless-stopped \
  -p 127.0.0.1:5678:5678 \
  -e GENERIC_TIMEZONE="Asia/Kuala_Lumpur" -e TZ="Asia/Kuala_Lumpur" \
  -e N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true \
  -v n8n_data:/home/node/.n8n \
  n8nio/n8n

# Di komputer anda (terminal baharu):
ssh -L 5678:localhost:5678 user@IP_SERVER

Kemudian buka http://localhost:5678 di komputer anda. Webhook dari luar tidak akan berfungsi dalam mod ini — ia untuk belajar/uji sahaja.

8. Ralat biasa

Simptom Punca biasa Penyelesaian
bind: address already in use (port 80/443) Apache/Nginx sudah berjalan Semak port (arahan di bawah jadual) → hentikan servis itu (sudo systemctl disable --now apache2 atau nginx)
permission denied ... /var/run/docker.sock Pengguna bukan ahli kumpulan docker Guna sudo, atau jalankan langkah usermod dalam Seksyen 4 dan log masuk semula
Pelayar tunjuk amaran sijil / sijil tak keluar DNS belum sampai, atau port 80/443 disekat Semak rekod A, ufw status, dan firewall di panel VPS. Lihat sudo docker compose logs traefik untuk ralat ACME
n8n restart berulang / Killed / lambat RAM tak cukup (OOM) Tambah swap (di bawah) atau naik taraf ke 2 GB RAM
EACCES: permission denied pada /files Pemilik folder local-files salah sudo chown -R 1000:1000 local-files (n8n berjalan sebagai UID 1000)
URL webhook tunjuk localhost:5678 Pemboleh ubah webhook tidak ditetapkan Pastikan N8N_WEBHOOK_URL (≥2.30.0) atau WEBHOOK_URL (versi lama) betul, kemudian docker compose up -d
docker-compose: command not found Guna arahan lama (v1) Guna docker compose (ada ruang, plugin v2)
Amaran secure cookie bila buka http://IP:5678 n8n menjangka HTTPS Guna domain + HTTPS, atau terowong SSH ke localhost

Semak siapa guna port 80/443:

sudo ss -tulpn | grep -E ':(80|443) '

Tambah swap 2 GB (untuk VPS 1 GB):

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
free -h

9. Seterusnya (pilihan)

Kemas kini n8n:

cd ~/n8n-compose
sudo docker compose pull
sudo docker compose down
sudo docker compose up -d

💡 Mahu lebih terkawal? Tetapkan versi, contoh image: n8nio/n8n:2.45.7, dan naikkan versi secara manual selepas baca nota keluaran. n8n keluarkan versi minor hampir setiap minggu; guna versi stable untuk produksi.

Backup volume data:

sudo docker volume ls     # cari nama volume, biasanya n8n-compose_n8n_data
sudo docker run --rm \
  -v n8n-compose_n8n_data:/data \
  -v "$(pwd)":/backup \
  alpine tar czf /backup/n8n_data-$(date +%F).tar.gz -C /data .

Simpan fail backup di luar VPS (contoh komputer anda atau storan awan).

Eksport aliran kerja (tambahan):

sudo docker compose exec n8n n8n export:workflow --all --output=/files/workflows-backup.json

Fail akan muncul dalam folder local-files/.

Keselamatan asas: kemas kini Ubuntu secara berkala (sudo apt upgrade), guna kunci SSH (bukan kata laluan), dan jangan dedahkan port 5678 secara terus ke internet.
